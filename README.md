# OPPO Experience & Service Store - Báo Cáo Sale & KPI Dashboard

## Hướng dẫn đưa lên GitHub & Deploy Vercel

1. Giải nén file `.zip` này.
2. Tạo một Repository mới trên GitHub và tải toàn bộ các file (`package.json`, `vite.config.js`, `index.html`, thư mục `src/`) lên repo.
3. Vào Vercel -> **Add New Project** -> Import repo từ GitHub -> Bấm **Deploy**.
